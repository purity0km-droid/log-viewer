Talklog Viewer
==============

talklog（zeta のトークを保存する非公式ツール）で書き出した HTML を、
zeta のトーク画面に近い見た目で読み返すためのビューアです。
zeta の公式ツールではありません。


■ 使い方
1. 公開ページ https://purity0km-droid.github.io/log-viewer/ をブラウザで開きます。
   zip で使うときは、zip を展開して（フォルダごと使ってください）、index.html をダブルクリックします。
2. 最初にトップ（概要・使い方・ビューア・再生モード・更新履歴）が出ます。
   どのページにも、吹き出しの形の紋章（ページの番号と漢字 1 字）が出ます。
   ログを開いていれば、概要に主役の立ち絵、右の列に登場人物と続きの発言が出ます。
   左下の ☀ / ☾ でトップの配色（ライト・ダーク）を切り替えられます。
3. talklog で保存した HTML を画面にドロップするか、「ファイルを選ぶ」から選びます。
   トップの「再生モード」から選ぶと、読み込んだあとそのまま再生します。
   ビューアの右上の「トップ」で、トップに戻れます。

読み込みはブラウザの中だけで行い、ログをどこかへ送信することはありません。
zip で使うときは、インターネットにつながっていなくても使えます。つながっているときは、トップと再生の表示に使うフォント
（Google Fonts の Zen Kaku Gothic New、jsDelivr の Overused Grotesk）と、再生で選んだフォントを取りに行きます
（つながっていなければ端末のフォントで表示します。ログの中身は送りません）。
Chrome・Edge などの最近のブラウザでお使いください。


■ 複数のログを切り替える
talklog の HTML を 1 つのフォルダにまとめておき、「フォルダを選ぶ」でそのフォルダを選びます
（フォルダを画面にドロップしても開けます）。
フォルダの中の talklog のファイルが新しい順に一覧になり、右上の「開く」からいつでも切り替えられます。
・一覧に出るのはフォルダの直下にあるファイルだけです（中のフォルダまでは見ません）。
・Chrome・Edge では選んだフォルダを覚えていて、次からは「前回のフォルダを開く」で開けます。
  ブラウザからフォルダを読む許可を求められたら、許可してください。
  後からフォルダに足したファイルも、「開く」で一覧を出し直すと反映されます。
・ファイルを選ぶ画面で、複数のファイルをまとめて選んでも一覧になります。
読んでいた位置はログごとに覚えているので、切り替えても続きから読めます。


■ アイコン
zip で使うときは、avatars フォルダに「話者名.png」という名前で画像を置くと、その話者のアイコンになります
（公開ページでは使えないので、下の「登場人物」から選んでください）。
jpg・jpeg・webp・gif も使えます。120px 前後の正方形の画像がおすすめです。
  例）話者名が「アオイ」なら avatars/アオイ.png
「アオイ（不安）」のように「（…）」が付いた名前は、「アオイ」のアイコンを使います。

ログを読み込んだ後、右上の「登場人物」かアイコンをクリックして、画像を選ぶこともできます。
この方法なら大きな画像もきれいに縮小され、このブラウザに保存されます。


■ 再生（立ち絵つきで 1 件ずつ流す）
右上の「▶ 再生」で、読んでいる位置からトークを 1 件ずつ文字送りで再生します。
キャラは左、自分は右に立ち、話している方が明るく前に出ます。
・立ち絵は「登場人物」の「立ち絵」から選びます。背景が透明な PNG は切り抜きのまま、
  四角い画像はカードとして出ます。立ち絵が無い人はアイコンを丸く出します。
・クリック・→ で送る、← で戻る、スペースで一時停止、F で全画面、Esc で終了。
  終えると再生を始めた画面（トップかビューア）に戻ります。ビューアは再生していた位置から読めます。
・速さ（ゆっくり・ふつう・速い・一括表示）は、再生中の下のボタンか、トップの「再生モード」で選べます。
・地の文やト書きの言葉（「店内」「寝室へ」「雨が」「夜の空気」「ピンクの光」など）から場面を推し量り、
  背景をその場所らしい絵や天気に変えます。違っていたら、下の「場面」ボタンの一覧で外したり、
  手で足したりできます（ログごとにこのブラウザに保存されます）。
・下の ☀ / ☾ で配色（ライト・ダーク）を切り替え、「Aa」で吹き出しや地の文のフォントを選べます。
  フォントは Google Fonts から読み込みます（インターネットが必要。つながっていないときは端末のフォントで表示します）。
・「● 録画」（または R キー）で再生のようすを動画（MP4 か WebM）で保存します。もう一度押すと止めて保存します。
  HTML-in-Canvas が使えないブラウザでは、画面の共有でこのタブを撮ります（ブラウザが許可を聞きます）。
・WebGL2 が使えるブラウザで動きます。Chrome で試験中の機能「HTML-in-Canvas」が
  使えるとき（chrome://flags の canvas-draw-element を有効にした場合など）は、
  文字のパネルにも効果がかかります。公開ページは Chrome の試験運用（オリジントライアル、2027 年 3 月 2 日まで）に
  参加しているので、対応する版の Chrome ならフラグを変えなくても使えます。右上に「HTML-IN-CANVAS」と出ます。
  トップも、目次・見出し・パネル・紋章の文字を canvas に描いて、溶けながら出てきます。


■ そのほかの機能
・前回読んでいた位置を覚えていて、次に開いたときは続きから表示します。
・画面上部の番号欄に番号を入れて Enter を押すと、その発言へ移動します。
・上部の色の見本で吹き出しのテーマ（ベーシック・オレオ・タロ）を、「Aa」で文字の大きさを変えられます。
・検索にはブラウザのページ内検索（Ctrl+F、Mac は ⌘F）を使ってください。


■ 保存されるデータ
選んだアイコン・立ち絵・表示設定・再生の速さ・場面の手直し・読んだ位置・前回のフォルダは、このブラウザの中に保存されます。
（フォルダについて保存するのは「どのフォルダか」だけで、ログの中身は保存しません。）
ブラウザの閲覧データ（Cookie とサイトデータ）を消すと、最初の状態に戻ります。
